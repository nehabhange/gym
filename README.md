# ELEVATE Fitness Website

A premium React website built with Vite, TypeScript, Tailwind CSS, Framer Motion, and GSAP.

## Features

- Modern dark luxury fitness design
- Responsive mobile-first layout
- GSAP ScrollTrigger reveal and parallax animations
- Framer Motion hover and transition interactions
- Sections for hero, about, programs, trainers, pricing, testimonials, contact, and footer
- Sticky navbar with transparent-to-solid background on scroll

## Getting Started

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Project Structure

- `src/App.tsx` — app shell and GSAP setup
- `src/components/` — reusable section components
- `src/index.css` — Tailwind setup and custom dark theme styles
- `tailwind.config.js` — Tailwind configuration
- `postcss.config.js` — PostCSS plugin configuration

## Notes

The site uses remote placeholder imagery for the hero and trainer sections, which can be replaced with custom brand assets for a production release.
